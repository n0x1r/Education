01 / Start here

Linux is an operating-system family built around the Linux kernel. A terminal is where you type commands; a shell such as Bash interprets them. The CLI is the text-based alternative to a GUI. The app you have is a reference library, not a shell that executes commands.

On Android, Termux supplies a terminal and packages. Kali and Ubuntu are Linux distributions; an unrooted PRoot environment does not give you Android root privileges. Many examples below are for a conventional Linux system and will need different packages or permissions on Android.

Read a command before running it

ls -lah ~/linux-lab

ls = list directory entries; -l = detailed listing; -a = include hidden entries; -h = readable sizes; ~ = home directory; ~/linux-lab = target path. Options are case-sensitive and are not universal between commands.

How to read documentation

TLDR gives examples. Synopsis describes syntax. Description explains purpose. Parameters explain flags and arguments. Filter expressions select data. Install shows package-manager alternatives. Caveats describe limitations. A man page is a detailed manual.

In a synopsis, [OPTION] usually means optional; FILE is a placeholder; ... means repetition. A leading $ is commonly an ordinary-user prompt, while # can indicate a root prompt. Do not copy prompt characters into the command.

First hands-on exercise

mkdir -p ~/linux-lab
cd ~/linux-lab
pwd
printf '%s\n' 'hello Linux' 'practice log' > notes.txt
ls -lah
cat notes.txt
grep -in 'practice' notes.txt
sha256sum notes.txt

This creates a practice directory and writes a new text file, then lists it, searches it and computes a SHA-256 hash. Run in a fresh lab directory; > overwrites an existing notes.txt. A hash is a fingerprint of file contents, not proof of authorship.

Never run an unfamiliar command with sudo. Avoid deleting, repairing, imaging or altering original evidence. Practice on your own files, isolated lab systems and authorized sample captures.

Common symbols

Permissions example

-rw-r-----  1 user group  128 Nov 26 08:00 notes.txt

The first character shows file type; next three permissions are owner, next three group, last three others. Here the owner can read and write; group can read; others have no access. Octal equivalent: 640.
