# Education
This repo contains documents and apps pertaining to education on cyber security and penetration testing.

## Linux learning application

[Rooted](linux/README.md) is a Python-powered interactive course covering Linux fundamentals, commands, file management, system administration, networking, cybersecurity, digital forensics and automation. It includes 56 lessons, 131 guided tasks, 112 questions and real Linux practice worksheets.

```bash
cd linux
python3 -m rooted.app --open
```
